Eval Platform

A control plane for LLM and agent quality so teams can author specs, run benchmarks, and review results without each product inventing its own harness.

Problem

Agent quality tends to live in notebooks and one-off scripts. There is no shared way to version an eval spec, launch a run, or sit a human on the outputs before something ships. Offline tests and live traffic then never meet in one place.

What I built

An eval service behind the gateway. Specs are authored in a React builder, versioned, and executed as jobs. A human-in-the-loop dashboard is the review surface: runs, golden sets, judges, and guardrails. The gateway owns policy and audit; the eval service scores. Quality gates sit in front of agents instead of after an incident.

Stack

  • Python and FastAPI for the scoring service
  • React for the spec builder and review dashboard
  • The AI gateway as the control plane (auth, spec versions, run audit)
  • AWS for job launch and the runtime

Outcome

Eval is platform work: write a spec, run it, review it. Callers do not each own a scoring stack. This page does not cite accuracy or pass-rate numbers.
