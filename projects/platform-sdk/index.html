AI Platform SDK

A shared Python SDK for auth, tools, memory, and agent graphs. I contribute; I did not author the whole library.

Problem

Each AI app tends to grow its own auth path, tool calls, and agent loop. Memory and tracing then get copied, or skipped. There is no shared way to hydrate context or emit spans.

What I contributed

Work on the platform SDK around memory hydration and OpenTelemetry so agent graphs can pull the right context and emit traces like any other service. The SDK also covers auth, tool orchestration, and guardrails; those are team-owned. My slice is the wiring that makes memory and observability usable from application code.

Stack

  • Python
  • LangGraph for agent graphs
  • Pydantic for models and validation
  • OpenTelemetry for traces

Outcome

App teams can hydrate memory and trace a graph without each repo inventing that layer. No adoption or latency figures on this page.
