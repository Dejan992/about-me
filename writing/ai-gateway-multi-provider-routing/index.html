AI gateway multi-provider routing

16 Sep 2026 Stub

If every IDE and app speaks tools and model APIs on its own, you get duplicated auth, duplicated protocol handling, and a deploy whenever routing policy changes. A gateway is the boring fix: one URL, MCP sessions for tools, tenant config in one place.

The part I own is making that gateway a production system. Hot reload matters because tenant settings change more often than code. CDK, ECS, and Datadog are how it stays up and visible. Product surfaces on the same stack are team-owned.

This stub stops at the design. The project page has the infra stack. I will add failure modes here later. No traffic charts until I have numbers I am willing to publish.
