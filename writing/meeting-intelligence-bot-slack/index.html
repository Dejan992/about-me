Meeting intelligence bot in Slack

16 Sep 2026 Stub

People already live in Slack. The bot I built stays there: calendar audits, post-meeting summaries, and action item tracking. It is async Python on Slack Bolt, running on AWS ECS. Typing indicators matter because those jobs are not instant, and a silent bot looks broken.

The hard part is not the summary prompt. It is multi-provider OAuth and credential storage so calendar and meeting sources can be connected without dropping secrets into a channel or a repo. The home page lists the stack: Python, Slack Bolt, AWS ECS, OAuth 2.0, async/await.

This stub is the shape of the system. I will add the event flow and how summaries get posted back when I write that down. No meeting-volume stats here.
